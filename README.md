# Xiayh0107 Tap

## How do I install these formulae?

`brew install xiayh0107/tap/<formula>`

Or `brew tap xiayh0107/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "xiayh0107/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
